# 问题修复与优化记录 (Maintenance & Optimization Record)

本文档用于记录 Bilberry 项目中的功能修复、性能优化以及 UI/UX 体验改进。

## [2026-05-04]

### 🔍 搜索体验优化 (Search UX Optimizations)
- **关键字高亮增强**：
    - 在 `app.css` 中引入了 `--selection-bg` 变量，统一了不同主题下的选中背景色。
    - 将编辑器选中颜色改为更醒目的**亮蓝色**（浅色模式 `rgba(37, 99, 235, 0.5)`，深色模式 `rgba(0, 122, 204, 0.7)`），解决了在某些主题下关键字看不清的问题。
- **搜索结果自动居中**：
    - 优化了点击搜索结果后的跳转逻辑。现在编辑器会自动将选中的关键字滚动到**视图中心区域**（`y: "center"`），避免显示在最上方或最下方被遮挡或忽视。

### 📑 标签栏优化 (TabBar Optimizations)
- **隐藏冗余滚动条**：移除了标签栏底部的原生滚动条，解决了文件过多时滚动条遮挡页签文字的问题。
- **支持鼠标滚轮滚动**：添加了 `onwheel` 事件监听，支持使用鼠标滚轮直接在标签栏进行水平滚动。
- **自动聚焦活跃页签**：切换文件或新开文件时，活跃页签会自动平滑滚动到可视区域内。

### 📂 目录树优化 (File Explorer Optimizations)
- **长文件名悬停提示**：为目录树的文件和目录项添加了 `title` 属性。当文件名因长度限制被省略号（`...`）截断时，鼠标悬停即可显示完整的文件名。

### 🖥️ 窗口交互优化 (Window Interaction Optimizations)
- **双击标题栏切换最大化**：在标签栏（标题栏区域）添加了双击事件。双击可切换窗口的最大化与还原状态，符合 macOS 用户的操作习惯。
